# Contributing

Thank you for your interest in contributing to MindsDB! We appreciate your time and effort in helping us improve the project.

## Getting Started

To get started with contributing to MindsDB, please follow these steps:

1. Fork the MindsDB repository on GitHub.
2. Clone your forked repository to your local machine.
3. Create a new branch for your changes.
4. Make your changes to the codebase.
5. Test your changes to ensure they work as expected.
6. Commit your changes and push them to your forked repository.
7. Submit a pull request to the MindsDB repository.

## Code of Conduct

Please note that we have a [Code of Conduct](https://github.com/mindsdb/mindsdb/blob/master/CODE_OF_CONDUCT.md) that all contributors must adhere to. By participating in this project, you agree to abide by its terms.

## Contributing Guidelines

To ensure a smooth and efficient contribution process, please follow these guidelines:

1. Make sure your code follows the project's coding standards and conventions.
2. Write clear and concise commit messages that describe the changes you've made.
3. Include tests for your changes to ensure they work as expected.
4. Update the documentation to reflect your changes.
5. Make sure your pull request is up to date with the latest changes in the main branch.
