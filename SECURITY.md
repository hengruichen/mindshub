# Security Policy

## Supported Versions

We actively support the following versions of MindsDB:

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in MindsDB, please report it to us immediately. Please do not disclose the vulnerability publicly until we have had a chance to address it.

To report a vulnerability, please send an email to [security@mindsdb.com](mailto:security@mindsdb.com) with the following information:

- A detailed description of the vulnerability
- Steps to reproduce the vulnerability
- Any potential impact of the vulnerability
- Your contact information (name, email, etc.)

We will acknowledge your report within 24 hours and will work with you to address the vulnerability as quickly as possible.

## Security Best Practices

To help ensure the security of your MindsDB installation, we recommend the following best practices:

- Keep your MindsDB installation up to date with the latest security patches
- Use strong, unique passwords for all user accounts
- Enable two-factor authentication (2FA) for all user accounts
- Regularly review and update your MindsDB configuration
- Monitor your MindsDB logs for suspicious activity
- Keep your operating system and other software up to date with the latest security patches

## Security Features

MindsDB includes a number of security features to help protect your data and prevent unauthorized access:

- Role-based access control (RBAC) to restrict access to specific resources
- Encryption of sensitive data at rest and in transit
- Support for SSL/TLS encryption for secure communication
- Support for LDAP authentication and authorization
- Support for OAuth2 authentication and authorization

## Security Updates

We will notify you of any security updates or patches as soon as they are available. You can subscribe to our security mailing list to receive these notifications.

## Security Team

The MindsDB security team is responsible for maintaining the security of the MindsDB project and responding to security incidents. The team includes members from the MindsDB development team, security experts, and external consultants.

## Security Policy Updates

This security policy is subject to change at any time. We will notify you of any changes to this policy as soon as they are available.
